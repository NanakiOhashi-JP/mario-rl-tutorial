# Goomba template cutter

`observation`の元画像から、クリボーの16×16ピクセルのテンプレートを切り出すツールです。

## 実行

プロジェクトのルートディレクトリで実行します。

```bash
uv run python cut-goomba/main.py
```

最初のクリボーが十分に表示されると、ゲームは自動で停止します。

## 操作

- `S`：切り出す範囲を選択する
- `Space`：一時停止する／再開する
- `N`：停止中に1フレーム進める
- `Q`：終了する

`S`を押したら、マウスでクリボー全体を囲み、`Enter`で決定します。選択範囲の中心を基準に、元画像から16×16ピクセルで自動的に切り出します。

プレビューで問題なければ`Y`で保存します。やり直す場合は`N`を押します。

保存先は`cut-goomba/templates/`です。既存ファイルは上書きせず、次のように連番で保存します。

```text
cut-goomba/templates/
├── goomba_1.png
└── goomba_2.png
```
